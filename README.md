# Multimodal Sentiment & Emotion Analyzer

Features:

- Positive / Neutral / Negative text classification
- Text prediction confidence
- Interactive text probability charts
- Clause-Level Text Conflict Score
- Clause-by-clause sentiment explanation
- Real-time facial-expression analysis
- Seven facial-expression classes
- Live facial confidence percentages
- Facial emotion bar and donut charts
- Live confidence history
- Qualitative text-face consistency analysis
- Dataset and model analytics dashboard

## Text Conflict Score

The numeric Conflict Score belongs only to text analysis.

It measures sentiment disagreement between independently
classified clauses and is separate from overall prediction confidence.

## Facial Analysis

Supported pretrained labels:

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

The facial model estimates visible expression patterns and does not
determine a person's true internal emotional state.

## Cross-Modal Analysis

Possible qualitative states:

- Consistent
- Emotion-Text Mismatch Detected
- Ambiguous / Insufficient Evidence

No numeric cross-modal conflict score is calculated.
